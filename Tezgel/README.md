## Brand-Block

Steht in jedem Prompt schon drin. Für eigene neue Prompts: Block + Szene + `Headline: "…"`.

```text
Brand style for an owner-run tiling company in Germany known for precise large-format tiles, walk-in showers without a step, balconies and stairs. Look: calm architectural interior photography; razor-straight joints; perfectly level surfaces; soft natural side light that reveals texture; realistic materials (porcelain stoneware, mosaic, natural stone); no clutter, no tools lying around. Palette: light zinc grey (#F4F4F5), anthracite text (#27272A), warm stone and greige tones, one accent colour red (#D82020) used sparingly. Typography: clean modern sans-serif headline, left-aligned, generous whitespace, at most two text sizes. People: only hands or figures from behind, never a recognisable face. Layout: vertical 3:4 portrait format (1080x1440 proportions); keep all text and key objects inside an 8% safe margin; keep the bottom-right corner (14% of the width) empty for a logo added later. Do not draw any logo, company name, brand name or watermark. Text rules: render ONLY the German text given in quotes, exactly once, verbatim, with correct umlauts (ä, ö, ü, ß); no other words or numbers.
```

Story-Variante: statt `vertical 3:4 portrait format (1080x1440 proportions)` steht `vertical 9:16 format (1080x1920 proportions); keep the top 14% and bottom 20% free of text`.
